# ProofPATH synthetic Vercel demonstration API

This read-only synthetic demo is not suitable for real safety incidents or survivor evidence. It uses ephemeral `/tmp` SQLite and file storage; the data may disappear at any time. Uploads, saved case changes, guardian contacts and SOS actions are blocked. Only synthetic record reads, what-if scenarios, privacy previews and synthetic PDF generation are allowed.

A production deployment needs authentication, per-user access restrictions, durable encrypted database/object storage, deletion controls, security review and verified notification delivery if offered. The full local backend remains in `app/main.py`.
